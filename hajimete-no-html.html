HTML とは？

HTML は、ページの骨格を作る言語です。見出し、段落、リンク、リストなどをタグで囲んで、ブラウザに「これは何の部品か」を伝えます。

よく使うタグ

  • <h1> … いちばん大きな見出し
  • <p> … 段落（文章のかたまり）
  • <a> … リンク
  • <ul> / <li> … 箇条書き
  • <strong> … 強調
